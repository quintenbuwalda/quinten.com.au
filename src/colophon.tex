\section{so what's up with this website?}
This website's content is written in \LaTeX\; syntax and then compiled with \href{https://ctan.org/pkg/lwarp}{lwarp} into HTML.
This compilation happens in \inline{/media/ghactions.png}{ghactions} Github Actions from the website's repo and 
the generated static files are pushed to a Cloudflare Worker and hosted under this domain.
